## 📖 About the Project

**Sufaraa Al-Thikr Center Management System** is an academic software engineering and desktop development project designed to digitize administrative and educational workflows for **Sufaraa Al-Thikr Quran Center**.

The project spans the full software development lifecycle—from requirements gathering, formal **Software Requirements Specification (SRS)**, **UML modeling**, and **relational database design (ERD)** to a working **C# Windows Forms** desktop implementation supporting centralized administration alongside dedicated teacher and student workflows.

<a id="features"></a>
## ✨ Core Features

- 🏛️ **Centralized Admin Dashboard** — Manage center operations, records, and administrative workflows from a unified desktop interface.
- 👨‍🏫 **Teachers & Students Interfaces** — Structured modules supporting teacher and student management within the Quran center.
- 🗂️ **Relational Data Modeling** — Built upon a normalized Entity-Relationship design to keep center records consistent and maintainable.
- 📄 **Full Software Engineering Documentation** — Includes complete system analysis artifacts stored under the [`docs/`](./docs) directory.

<a id="documentation"></a>
## 📐 System Analysis & Documentation 

All system analysis and design deliverables are organized inside the [`docs/`](./docs) folder:

- **Software Requirements Specification (SRS)** — Problem statement, functional & non-functional requirements, and system scope.
- **UML Diagrams** — Use Case Diagrams and Class Diagrams modeling actors, interactions, and object structure.
- **Database Design (ERD)** — Entity-Relationship Diagram detailing entities, attributes, and relationships.

<a id="getting-started"></a>
## 🚀 Getting Started

### Prerequisites

- **Visual Studio** with the **.NET Desktop Development** workload installed.

### Run Locally

```bash
git clone [https://github.com/ReemMohsn/Sufaraa-Althikr-Center-Management-System.git](https://github.com/ReemMohsn/Sufaraa-Althikr-Center-Management-System.git)
cd Sufaraa-Althikr-Center-Management-System
```

1. Open the `.sln` solution file in **Visual Studio**.
2. Restore NuGet packages if prompted and update any local database connection settings (if applicable).
3. Press **F5** to build and run the Windows Forms application.
